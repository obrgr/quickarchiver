QuickArchiver

QuickArchiver helps you keep your inbox clean. It learns where messages belong and lets you archive matching messages later with a single click or keyboard shortcut.

Quick Start

1. Create a rule by moving a message

Move a message to its destination folder as usual. If no matching rule exists, QuickArchiver automatically creates one from the sender address and remembers the destination folder.

2. Archive matching messages

When a message matches a rule, click the QuickArchiver button or press Alt+A. QuickArchiver moves it directly to the saved destination folder. With multiple messages selected, Alt+A moves each message for which a rule exists.

Tip: Show the destination folder in the message list

Enable the QuickArchiver Folder column in Thunderbird's table view to see the matching destination before moving a message. Details are provided below.

Details

Rule popup and rule settings

The rule popup lets you choose which conditions are active. A rule can match the sender, recipients, subject, and optionally the source account. All enabled conditions must match.

You can also select the destination with a searchable folder picker and filter that list by account.

Text conditions are case-insensitive and support * as a wildcard. For example, @*example.com matches both info@newsletter.example.com and support@example.com. A value without an explicit wildcard also matches when it is contained anywhere in the corresponding field.

Enable Open rule popup for new rules to review every automatically created rule immediately. With this option enabled, special destinations such as Trash are also allowed; otherwise Inbox and Trash are excluded from automatic rule creation.

Context menu

Right-click the QuickArchiver button to edit the current rule, show all rules, change whether the rule popup opens for new rules, or open this About page. In the message list, the menu also provides the move action when a matching rule exists.

Show the QuickArchiver folder column

In Thunderbird's table view, right-click any column heading and select QuickArchiver Folder. The column displays the destination folder for matching rules. If a message is already there, it displays ✓ Current Folder. The column is not available in card view.

Settings and rule management

All rules

Select Show all rules from the context menu or the QuickArchiver settings page to review, edit, or delete stored rules.

Import and export

Open the tools below the rules list to export all rules as a JSON backup or import a previous backup. Importing replaces all existing rules, so export a backup first if they are still needed.

Release Notes

Version 2.6.1

  • Improved runtime message handling for reliable operation with Manifest V3
  • Added an add-on icon to the manifest

Version 2.6

  • Added a folder picker with search and account filtering to the rule editor
  • Added account information to the rules list
  • Improved the rule editor, folder picker, rules list, and import/export tools

Version 2.5

  • Rules can optionally be restricted to messages from a selected source account
  • Improved rule matching and handling of moved messages

Version 2.4

  • Added an optional rule dialog for reviewing newly created rules
  • Improved cleanup of stored rules

Version 2.3

Compatibility improvements for newer Thunderbird versions.

  • Added the QuickArchiver folder column in the message list's table view
  • Improved compatibility with the current WebExtension APIs
  • Added an option to open the rule popup when creating new rules

Version 2.2

New features:

  • Added a QuickArchiver settings page (see Add-ons Manager → QuickArchiver)
  • Rules now support wildcards ('*'). For example, '@*example.com' matches messages from info@newsletter.example.com and support@example.com.

Version 2.1

Warning: With Thunderbird's default settings, stored QuickArchiver rules are lost when the extension is uninstalled. The import and export tools can be used to back up the rules first. In theory, you can transfer the rules to another Thunderbird installation if the account and folder structure is identical (untested).

New features:

  • Import and export of all rules in JSON format
  • Improved appearance and usability of the rules list
  • Fixed initialization on first start

Version 2.0

Thunderbird 115 (Supernova) required substantial changes to QuickArchiver. The old QuickArchiver 0.2 branch no longer works and will not be developed further. Earlier Thunderbird updates had already made it clear that continuing to support it would require significant effort and undesirable compromises.

The good news: there is a new version and you have just installed it!

New features:

  • Complete redevelopment based on Mozilla's current WebExtension API, making future updates easier
  • Rules are stored in WebExtension storage
  • Rules may become available across devices in the future
  • New interface with a toolbar button, menu, and keyboard shortcuts
  • Improved rule editor and list of all rules
  • Rules are still created automatically when messages are moved

Some limitations remain:

  • All rules have to be created again. Migrating the old rule database to the new structure would be very time-consuming.
  • The QuickArchiver folder column is not available in Thunderbird's card view. In table view, it can be enabled from the column picker. Moving messages can also be done with the toolbar button and keyboard shortcuts.
