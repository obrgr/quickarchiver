QuickArchiver helps you keep your inbox clean. It learns where messages belong and lets you archive matching messages later with a single click or keyboard shortcut.

NEW: QuickArchiver also automatically tags messages based on your rules, keeping categories visible before you move messages out of your inbox.

QuickArchiver supports an email workflow based on the Getting Things Done (GTD) method. You can use your inbox as a collection point for new information and decide what comes next as you review each message: reply straight away, capture a task, wait for a response, or file the message for reference. Once you have completed the necessary action or recorded it somewhere you trust, QuickArchiver helps with filing. For example, move the first invoice from a sender into your invoices folder; later matching messages can go there with one click or a keyboard shortcut. This makes it easier to see which messages in your inbox still need your attention. You decide when a message is ready to be filed, while continuing to manage tasks and follow-ups in your usual system.

Quick Start

1. Create a rule by moving a message

Move a message to its destination folder as usual. If no matching rule exists, QuickArchiver automatically creates one from the sender address and remembers the destination folder.

2. Archive matching messages

When a message matches a rule, click the QuickArchiver button or press Alt+A. QuickArchiver moves it directly to the saved destination folder. With multiple messages selected, Alt+A moves each message for which a rule exists.

Tip: Show the destination folder in the message list

Enable the QuickArchiver Folder column in Thunderbird's table view to see the matching destination before moving a message. Details are provided below.

Details

Rule popup and rule settings

The rule popup lets you choose which conditions are active. A rule can match the sender, recipients, subject, and optionally the source account. All enabled conditions must match.

You can also select the destination with a searchable folder picker and filter that list by account.

Text conditions are case-insensitive and support * as a wildcard. For example, @*example.com matches both info@newsletter.example.com and support@example.com. A value without an explicit wildcard also matches when it is contained anywhere in the corresponding field.

Enable Open rule popup for new rules to review every automatically created rule immediately. With this option enabled, special destinations such as Trash are also allowed; otherwise Inbox and Trash are excluded from automatic rule creation.

Context menu

Right-click the QuickArchiver button to edit the current rule, show all rules, change whether the rule popup opens for new rules, or open this About page. In the message list, the menu also provides the move action when a matching rule exists.

Show the QuickArchiver folder column

In Thunderbird's table view, right-click any column heading and select QuickArchiver Folder. The column displays the destination folder for matching rules. If a message is already there, it displays ✓ Current Folder. The column is not available in card view.

Open Add-ons Manager → QuickArchiver → Settings to configure the column. Show folder path in the folder column is enabled by default. Disable it to show only the folder name, for example → Invoices instead of → Invoices (Archive).

The subordinate option Hide folder path for tagged messages is disabled by default. When enabled, it hides the path for messages that already have Thunderbird tags, including manually assigned tags. Untagged messages keep the path. This checks the message's actual tags, rather than tags configured on its matching rule. If the main setting is off, only the folder name is shown regardless of tags, and the subordinate option is disabled.

Changes update the column immediately. The toolbar tooltip keeps the detailed path, and ✓ Current Folder is unchanged.

NEW: Automatically tag messages

QuickArchiver can add Thunderbird tags to matching messages while they are still in your inbox. Keep categories such as Customers, Invoices, or projects visible before archiving. Tagging is optional: rules without direct or inherited tags work as before. You still decide when to move messages with QuickArchiver.

Assign tags to a rule

  1. Open a rule from the QuickArchiver menu or through Show all rules and Edit.
  2. Choose which messages match under Conditions, then select a destination under Actions.
  3. Under Tags, select one or more existing Thunderbird tags. Their names appear in their tag colors.
  4. Click Save rule.

For example, a supplier rule can point to Invoices/Supplier A and add the tag Invoices. New matching mail receives that tag in the inbox. The message moves to the destination only when you archive it.

If several rules match, QuickArchiver uses the first matching rule in the stored list. Its own tags combine with applicable folder tags; tags from every matching rule are not combined.

Inherit tags from parent folders

Under Actions → Parent folder tags in the rule dialog, choose Add folder mapping and assign tags to the destination itself or one of its parents. The mapping applies to that folder and all its subfolders in the same account. Save rule saves both the rule and folder mappings; Cancel discards the draft changes.

The dialog shows only mappings relevant to the current destination. Changing the destination updates the view; other mappings remain saved. Each mapping affects all rules whose destination is in that folder tree, including rules created later.

For example, a rule has the destination Customers/Example Ltd/Project A:

  • Customers contributes the tag Customers.
  • Customers/Example Ltd contributes the tag Example Ltd.
  • The rule itself contributes the tag Invoices.

The message receives all three tags. Multiple levels add together; duplicate tags are applied only once. The preview names inherited tags and their source folders.

Inheritance follows the matching rule’s destination, not the message’s current folder. An identically named folder in another account or a sibling named Customers-old does not inherit from Customers. A folder mapping alone does not replace a matching message rule.

When tags are applied

  • When new mail arrives, without opening or archiving it.
  • When you open a folder, for matching messages already in it.
  • When QuickArchiver initializes, for open folders.
  • After saving rule or folder-tag changes, for matching messages in open folders.
  • When displaying an individual message or archiving it with QuickArchiver.

Other folders are checked when you open them. Saving does not scan the entire mailbox. Large folders may be processed progressively. Thunderbird’s available tag list is loaded only when needed, once per processing run.

Manage tags and understand changes

Use Manage tags in Thunderbird… to open Thunderbird’s tag settings. Create, rename, recolor, or delete tags there. Returning to the rule dialog refreshes its choices while keeping your unsaved settings.

Existing message tags are preserved; QuickArchiver adds only missing tags. Renaming or recoloring an existing tag keeps its assignment. Deleted references may remain visible by their internal key when editing; they are skipped when tagging messages.

Removing a tag selection or folder mapping does not remove tags already applied to messages. It stops future additions from that assignment. Another assignment may still require the same tag. Removing such a tag manually from a message allows QuickArchiver to add it again on the next check.

Overview and backups

Show all rules displays each rule’s conditions first, then its destination and direct and inherited tags. Fields adapt to the window width. Hover over an inherited tag to see its source folders. All folder mappings are listed below; delete them there after confirmation. To edit their tags, open a rule for a destination in the relevant folder tree.

JSON exports include rule tags and folder mappings. Importing these new backups replaces rules and folder mappings. Legacy backups containing only a rule array remain supported and leave existing folder mappings unchanged. Export your current settings before importing if you want to keep them.

Backups contain tag references, not Thunderbird tag definitions with names and colors. Importing does not create missing tags. When moving settings to another profile, the referenced tags, accounts, and destination folders must also be available.

Settings and rule management

All rules

Select Show all rules from the context menu or the QuickArchiver settings page to review, edit, or delete stored rules.

Import and export

Open the tools below the rules list to export all rules as a JSON backup or import a previous backup. Importing replaces all existing rules, so export a backup first if they are still needed.

Version 2.0

Thunderbird 115 (Supernova) required substantial changes to QuickArchiver. The old QuickArchiver 0.2 branch no longer works and will not be developed further. Earlier Thunderbird updates had already made it clear that continuing to support it would require significant effort and undesirable compromises.

The good news: there is a new version and you have just installed it!

New features:

  • Complete redevelopment based on Mozilla's current WebExtension API, making future updates easier
  • Rules are stored in WebExtension storage
  • Rules may become available across devices in the future
  • New interface with a toolbar button, menu, and keyboard shortcuts
  • Improved rule editor and list of all rules
  • Rules are still created automatically when messages are moved

Some limitations remain:

  • All rules have to be created again. Migrating the old rule database to the new structure would be very time-consuming.
  • The QuickArchiver folder column is not available in Thunderbird's card view. In table view, it can be enabled from the column picker. Moving messages can also be done with the toolbar button and keyboard shortcuts.
