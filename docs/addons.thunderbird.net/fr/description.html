Une boîte de réception bien rangée, en moins de clics Lettres d’information, factures, demandes de clients ou messages de votre association : de nombreux e-mails vont régulièrement dans les mêmes dossiers. QuickArchiver mémorise ces destinations pour vous éviter de chercher le bon dossier à chaque fois. QuickArchiver accompagne votre gestion des e-mails selon la méthode Getting Things Done (GTD) : une fois que vous avez décidé quoi faire d’un message, le classement rapide vous aide à garder une boîte de réception bien rangée. Vous décidez quand déplacer un message. QuickArchiver trouve la destination correspondante : un clic ou un raccourci clavier suffit pour le classer. Déplacez une fois, gagnez du temps ensuite Déplacez un e-mail vers son dossier de destination comme d’habitude. Si aucune règle ne correspond, QuickArchiver en crée automatiquement une à partir de l’adresse de l’expéditeur et mémorise le dossier. Lorsqu’un autre message correspondant arrive, cliquez sur le bouton QuickArchiver ou appuyez sur Alt+A. Le message rejoint directement le dossier enregistré. Vous pouvez aussi sélectionner plusieurs messages et utiliser Alt+A pour déplacer chacun de ceux pour lesquels une règle existe. Vos règles se construisent au fil du rangement quotidien. Inutile de créer à l’avance un filtre pour chaque expéditeur. Voyez la destination avant de déplacer le message L’infobulle du bouton QuickArchiver indique le dossier de destination et le raccourci clavier actuellement configuré. Dans la vue en tableau de Thunderbird, vous pouvez aussi activer la colonne Dossier QuickArchiver : faites un clic droit sur un en-tête de colonne et sélectionnez-la. Les destinations apparaissent alors directement dans la liste des messages. Si un message est déjà au bon endroit, la colonne affiche ✓ Dossier actuel. Cette colonne n’est pas disponible dans la vue en fiches. Des règles adaptées à votre classement Modifiez vos règles selon l’expéditeur, le destinataire ou l’objet, et limitez-les si nécessaire à un compte source précis. Toutes les conditions activées doivent être satisfaites. Les règles portant sur le destinataire vérifient la première adresse de destinataire fournie par Thunderbird. La recherche ne distingue pas les majuscules des minuscules. Le texte recherché peut apparaître n’importe où dans le champ. Vous pouvez aussi utiliser * comme caractère générique : @*example.com correspond par exemple à info@newsletter.example.com et à support@example.com. Choisissez le dossier de destination à l’aide du sélecteur avec recherche. Si vous utilisez plusieurs comptes, filtrez la liste des dossiers par compte. Gardez le contrôle de vos règles Faites un clic droit sur le bouton QuickArchiver pour ouvrir son menu. Vous pouvez y modifier la règle actuelle, sélectionner Afficher toutes les règles ou consulter l’aide intégrée. La liste des règles permet de vérifier, modifier et supprimer les règles enregistrées. Pour vérifier immédiatement chaque nouvelle règle, activez Ouvrir l’éditeur pour les nouvelles règles dans les options. L’éditeur s’ouvrira après la création automatique d’une règle. Cette option autorise aussi les destinations spéciales comme la corbeille ; sinon, la boîte de réception et la corbeille sont exclues de la création automatique de règles. Sauvegardez et restaurez vos règles Les outils d’importation et d’exportation sous la liste des règles permettent de les enregistrer dans un fichier et de les restaurer plus tard. L’importation remplace toutes les règles existantes. Exportez d’abord une sauvegarde si vous souhaitez les conserver. Les règles sont enregistrées localement dans Thunderbird. Sauvegardez-les également avant de désinstaller l’extension si vous souhaitez les réutiliser plus tard. Langues et informations complémentaires QuickArchiver est disponible en français, en anglais et en allemand et prend en charge Thunderbird 128 à 156.
