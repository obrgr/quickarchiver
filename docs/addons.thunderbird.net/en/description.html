A tidy inbox, with fewer clicks Newsletters, invoices, customer enquiries, or messages from your club: many emails belong in the same folders time after time. QuickArchiver remembers those destinations so you can stop hunting for the right folder. QuickArchiver supports an email workflow based on the Getting Things Done (GTD) method: once you have decided what to do with a message, quick filing helps you keep your inbox clear. You decide when to move a message. QuickArchiver finds the matching destination – one click or a keyboard shortcut files it away. Move it once, save time next time Move an email to its destination folder as usual. If no matching rule exists, QuickArchiver automatically creates one from the sender’s address and remembers the folder. When another matching message arrives, click the QuickArchiver button or press Alt+A. The message goes straight to the saved destination. You can also select several messages and press Alt+A to move every message that has a matching rule. Your rules grow as you tidy your inbox. There is no need to set up a filter for every sender in advance. See where a message will go The QuickArchiver button’s tooltip shows the destination folder and your currently configured keyboard shortcut. In Thunderbird’s table view, you can also enable the QuickArchiver Folder column: right-click a column heading and select it. Destinations then appear directly in the message list. If a message is already in the right place, you will see ✓ Current Folder. This column is not available in card view. Rules that fit the way you file mail Adjust any rule to match the sender, recipient, or subject, and optionally restrict it to a particular source account. All enabled conditions must match. Recipient rules check the first recipient address provided by Thunderbird. Text matching ignores upper and lower case. Your search text can occur anywhere in the field. You can also use * as a wildcard: @*example.com, for example, matches both info@newsletter.example.com and support@example.com. Choose the destination folder using a searchable picker. If you have several accounts, filter the folder list by account. Automatically tag messages QuickArchiver can add Thunderbird tags to matching messages while they are still in your inbox. Keep categories such as Customers, Invoices, or projects visible before archiving. Tagging is optional: rules without direct or inherited tags work as before. You still decide when to move messages with QuickArchiver. Assign tags to a rule
  1. Open a rule from the QuickArchiver menu or through Show all rules and Edit.
  2. Choose which messages match under Conditions, then select a destination under Actions.
  3. Under Tags, select one or more existing Thunderbird tags. Their names appear in their tag colors.
  4. Click Save rule.
For example, a supplier rule can point to Invoices/Supplier A and add the tag Invoices. New matching mail receives that tag in the inbox. The message moves to the destination only when you archive it. If several rules match, QuickArchiver uses the first matching rule in the stored list. Its own tags combine with applicable folder tags; tags from every matching rule are not combined. Inherit tags from parent folders Under Actions → Parent folder tags in the rule dialog, choose Add folder mapping and assign tags to the destination itself or one of its parents. The mapping applies to that folder and all its subfolders in the same account. Save rule saves both the rule and folder mappings; Cancel discards the draft changes. The dialog shows only mappings relevant to the current destination. Changing the destination updates the view; other mappings remain saved. Each mapping affects all rules whose destination is in that folder tree, including rules created later. For example, a rule has the destination Customers/Example Ltd/Project A:
  • Customers contributes the tag Customers.
  • Customers/Example Ltd contributes the tag Example Ltd.
  • The rule itself contributes the tag Invoices.
The message receives all three tags. Multiple levels add together; duplicate tags are applied only once. The preview names inherited tags and their source folders. Inheritance follows the matching rule’s destination, not the message’s current folder. An identically named folder in another account or a sibling named Customers-old does not inherit from Customers. A folder mapping alone does not replace a matching message rule. When tags are applied
  • When new mail arrives, without opening or archiving it.
  • When you open a folder, for matching messages already in it.
  • When QuickArchiver initializes, for open folders.
  • After saving rule or folder-tag changes, for matching messages in open folders.
  • When displaying an individual message or archiving it with QuickArchiver.
Other folders are checked when you open them. Saving does not scan the entire mailbox. Large folders may be processed progressively. Thunderbird’s available tag list is loaded only when needed, once per processing run. Manage tags and understand changes Use Manage tags in Thunderbird… to open Thunderbird’s tag settings. Create, rename, recolor, or delete tags there. Returning to the rule dialog refreshes its choices while keeping your unsaved settings. Existing message tags are preserved; QuickArchiver adds only missing tags. Renaming or recoloring an existing tag keeps its assignment. Deleted references may remain visible by their internal key when editing; they are skipped when tagging messages. Removing a tag selection or folder mapping does not remove tags already applied to messages. It stops future additions from that assignment. Another assignment may still require the same tag. Removing such a tag manually from a message allows QuickArchiver to add it again on the next check. Overview and backups Show all rules displays each rule’s conditions first, then its destination and direct and inherited tags. Fields adapt to the window width. Hover over an inherited tag to see its source folders. All folder mappings are listed below; delete them there after confirmation. To edit their tags, open a rule for a destination in the relevant folder tree. JSON exports include rule tags and folder mappings. Importing these new backups replaces rules and folder mappings. Legacy backups containing only a rule array remain supported and leave existing folder mappings unchanged. Export your current settings before importing if you want to keep them. Backups contain tag references, not Thunderbird tag definitions with names and colors. Importing does not create missing tags. When moving settings to another profile, the referenced tags, accounts, and destination folders must also be available. Keep your rules under control Right-click the QuickArchiver button to open its menu. From there, edit the current rule, select Show all rules, or open the built-in help. The rules list lets you review, change, and delete saved rules. To review each new rule straight away, enable Open rule popup for new rules in the options. The editor will open after a rule is created automatically. This option also allows special destinations such as Trash; otherwise, Inbox and Trash are excluded from automatic rule creation. Back up and restore your rules Use the import/export tools below the rules list to save your rules to a file and restore them later. Importing replaces all existing rules. Export a backup first if you want to keep them. Rules are stored locally in Thunderbird. Back them up before uninstalling the extension if you want to use them again later. Languages and further information QuickArchiver is available in English, German, and French and supports Thunderbird 128 through 159.
