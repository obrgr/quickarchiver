# Release documentation

When updating release notes, add the newest version at the top of the full history in each localized About page under
`src/content/tab/de_DE/`, `src/content/tab/en_US/`, and `src/content/tab/fr/`.

Update the static release notes preview (`aside.release-preview`) in all three pages so it matches the first four
versions in the full history, newest first. When adding a fifth version to the preview, remove its oldest heading
and bullet list from the preview and keep them in the full history. Verify that all three previews show the same four
version numbers and retain the link to the full release notes.
